VSCode
######

Integration with VSCode is accomplished using the task interface.
This interface allows VSCode to run MHSG in a shell and extract the results.

Configuring
-----------

The task interface uses the task.json file to tell VSCode how to execute a task.
The file can be generated by choosing the menu option **Terminal->Configure Tasks...**...

.. image:: vscode_terminal_configure_tasks.png

...then choosing **Create tasks.json file from template**...

.. image:: vscode_create_json_file.png

...and finally choosing the **Others** option.

.. image:: vscode_others_options.png

This will create a template **task.json** file:

.. image:: vscode_template_json_file.png

Replace the contents of the template file with the following...

      "tasks": [
        {
          "label": "mhsg-check",
          "type": "shell",
          "command": "mhsg -f \"${relativeFile}\"",
          "problemMatcher": {
            "owner": "mhsg",
            "fileLocation": ["autoDetect", "${workspaceFolder}"],
            "pattern": [
              {
                "regexp": "^File:  ([^\\s]*)\\s*$",
                "file": 1
              },
              { // match =======
                "regexp": "^.*$"
              },

              },

                "regexp": "^.*$"
              },
              { // match Total Violations
                "regexp": "^.*$"
              },
              { // match Error count
                "regexp": "^.*$"
              },
              { // match Warning count
                "regexp": "^.*$"
              },
              { // match ------
                "regexp": "^.*$"
              },
              { // match Rule/severity/line/solution header
                "regexp": "^.*$"
              },
              { // match ------

Executing Task
--------------

The two tasks `mhsg-check` and `mhsg-fix` are available under the **Terminal=>Run Task...** menu option...

.. image:: vscode_terminal_run_task.png


Keybindings
-----------

A keybinding can be created to make it easier to run the `mhsg-check` and `mhsg-fix` tasks.
This involves creating a `keybindings.json` file.
This file is located in the same directory as the `tasks.json` file.

Copy the following into the `keybindings.json` file...

.. code-block:: json

    [
        {"key": "ctrl+f", "command": "workbench.action.tasks.runTask", "args": "mhsg-fix"},
        {"key": "ctrl+i", "command": "workbench.action.tasks.runTask", "args": "mhsg-check"}
    ]

...and save it to the same directory as the `task.json` file.

Now the open file buffer can be checked for errors using `ctrl+i`.

.. image:: vscode_file_with_errors.png

The violations are shown in the Problems tab:

.. image:: vscode_problems_tab.png

The violations can be fixed manually, or by using `ctrl+f`...

.. image:: vscode_file_fixed.png

Formatting with Format Document
-------------------------------

MHSG can also be used as the formatter for **Format Document** and format on save.
This uses the `Custom Local Formatters <https://marketplace.visualstudio.com/items?itemName=jkillian.custom-local-formatters>`_ extension, which runs a command with the document on standard input and replaces the document with the command's standard output.

Install the extension and add the following to your ``settings.json``:

.. code-block:: json

   {
     "customLocalFormatters.formatters": [
       {
         "command": "mhsg --stdin --fix --stdout -c ${workspaceFolder}/mhsg_config.yaml",
         "languages": ["vhdl"]
       }
     ]
   }

Remove the ``-c`` option if you do not use a configuration file.
